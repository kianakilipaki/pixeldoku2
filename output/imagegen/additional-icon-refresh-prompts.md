# Additional PixelDoku icon refresh

Built-in image generation, one call per asset. Transparent 64x64 PNGs resized with nearest-neighbor sampling. Originals preserved in `lib/assets/icons/originals-before-refresh/`.

### lib/assets/icons/pencil.png

References: approved star and original pencil.

Use case: style-transfer. One standalone transparent pixel-art UI icon for PixelDoku. Input 1 is approved star style reference; input 2 is old pencil;  Primary request: A diagonal golden-yellow wooden pencil, graphite tip pointing lower left, cream exposed wood, tiny cream ferrule and muted red eraser. Simple and readable. Match the star's chunky crisp pixel clusters, restrained dark-brown outline, bright upper-left cream highlights and lower-right shading, polished 16-bit game sprite. Exactly one icon centered on square canvas occupying about 80%, with transparent margin, no clipping. Actual transparent alpha background. No checkerboard painted in, no scene, button, panel, external shadow or glow halo, text or watermark. Broad pixel clusters and simple silhouette readable at 18-34 display pixels. Do not include reference star. Deliver only the pencil icon.
