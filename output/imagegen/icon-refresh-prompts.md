# PixelDoku icon refresh

Created using the built-in image-generation tool, one call per icon. Final assets are 64×64 transparent PNGs, resized with nearest-neighbor sampling. Existing asset paths are unchanged. Backups: `lib/assets/icons/originals-before-refresh/`.
